## Alasan Pemilihan Framework Bootstrap 5
Untuk proyek **KosHunter**, saya memilih **Bootstrap 5** karena:
- Komponen bawaannya lengkap banget (seperti `navbar`, `table`, `card`, dan `badge`) jadi nggak perlu bikin CSS manual dari nol lagi.
- Sistem grid dan kelas responsifnya gampang dipakai buat ngatur tampilan biar rapi pas dibuka di layar HP maupun laptop.
- Paling pas dan cepat buat bikin kerangka tampilan aplikasi katalog kos ini.
